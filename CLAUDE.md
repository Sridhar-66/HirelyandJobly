## Live Deployment & Vercel
- **Production URL**: https://hirelyandjobly.vercel.app/
- **Git to Vercel CI/CD**: The repository is linked to Vercel. **Every time you make updates/fixes, commit and push to Git (`git push origin main`) at the end** so that changes are immediately built and visible on the live site.

## Quick Reference
- **App Path**: `hirely-jobly`
- **Local Dev**: `cd hirely-jobly && npm run dev`
- **Build Check**: `cd hirely-jobly && npm run build`
- **Data & Configuration**: `hirely-jobly/data/content.ts`
- **Design Guidelines**: Refer to `ui_finalredesign.md` and `Project_brief.md`.
- **Deploy Command**: `git add -A && git commit -m "..." && git push origin main`
